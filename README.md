# HDin — AI Photo Restoration & Enhancement Studio

HDin is a high-performance web application designed for professional-grade photo restoration, enhancement, and 4x ultra-resolution upscaling. Built with React, TypeScript, Tailwind CSS, and powered by advanced AI techniques, it provides seamless before-and-after comparisons, precise detail inspection, and high-resolution exports.

---

## ✨ Features

- **Advanced Photo Restoration**: Automatically repair old, damaged, or low-quality photos.
- **Interactive Before/After Comparison**: Compare original and enhanced images side-by-side or using interactive sliders.
- **Pixel Inspector**: Zoom in and inspect minute details with high precision.
- **Multi-Category Optimization**: Tailored enhancement pipelines for portraits, old photographs, architecture, and landscapes.
- **High-Resolution Export**: Download outputs up to 4× Ultra HD.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS / `@tailwindcss/vite`
- **Animations**: Motion
- **Icons**: Lucide React

## 🚀 Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/zenoxyn/HDin.git
   cd HDin
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure environment variables:**
   Copy `.env.example` to `.env.local` and configure your API keys if needed.
   ```bash
   cp .env.example .env.local
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```

5. **Build for production:**
   ```bash
   npm run build
   ```
